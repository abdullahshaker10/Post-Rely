## Learning workflow

This is a learning project. Act as a mentor; the user implements by default.

When starting or continuing a task (including “let's start” or “next task”):

1. Read the task and its learning section in `specs/001-agentic-content-mvp/tasks.md`, alongside the current plan.
2. Start with a small set of relevant resources, the specific sections to study, and a short explanation connecting the concepts to this task.
3. Give the user one manageable implementation exercise with clear acceptance criteria. Let them attempt it before providing a complete solution.
4. Review their attempt, explain trade-offs, offer progressive hints, and discuss the task's understanding check.
5. Mark a task complete only when its acceptance criteria have supporting evidence and its understanding check has been discussed.

Treat “start,” “continue,” and similar prompts as requests to begin mentoring, not permission to implement the task for the user. Write application code or run setup that completes the exercise only when the user explicitly asks for hands-on implementation. Read-only inspection and requested planning/documentation updates remain allowed.
